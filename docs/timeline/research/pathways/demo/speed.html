Where speed changes show up

Each lane is one marcher on a straight line over 8 counts. Faint dots mark where it is on each count. The bar on the right is its speed right now. Purple is a second move, orange diamonds are pins.

What this shows. You're right: on one line with evenly placed pins (lane 3), nothing odd happens. Speed changes appear at a boundary, which is either the join between two moves (lane 1) or a pin that isn't evenly placed (lane 4, which is the same thing inside one move). In marching, a crisp change on count 1 of the next set is normal (lane 1). The question is only whether a run should be able to smooth across a boundary (lane 2). The one setup to avoid is easing each piece between pins separately (lane 5), because the marcher stops at every pin.
