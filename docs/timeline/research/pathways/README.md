## The goal

Marching shows need many kinds of pathway, and no single tool covers them. Some moves are drawn
and the counts barely matter (a run or a flutter). Some care exactly which count a marcher turns
on (block letters). Some are one marcher's path bent to dodge a collision. The only existing
attempt in a drill tool is known for being technically complete but hard to use. **The aim is to
simplify what a band typically does**, so the common cases take one gesture and the rare ones are
still possible, without a separate tool per case.

Design precedents come from animation tools and DAWs, not drill software
(motion paths with separate spatial and temporal curves, roving keyframes, time-stretch with a
modifier, clip lead-ins).

## Terms

- **Route**: the path a marcher (or a group, Q3) walks during one move, from where the move starts to where it ends. A list of points, each a corner or smooth.
- **Pin**: a point on a route tied to a count ("be here on count 4"). New in this work; the closest old idea is the page-era midset, which was never built. A midset is a pin at the half, quarter sets are pins at the quarters, a block-letter corner on a set count is a pin on that corner. Between two pins (or a move's start or end and a pin) the marcher walks at one constant speed (S-2).
- **Entry**: how a marcher not on a route gets onto it (a rejoin after a takeover, or joining a follow the leader).
- **Trail**: the single line a follow-the-leader move walks, one marcher behind another (spec R-9).
- **Slot**: a place along a trail that a marcher can end on. On a shape these are the shape's spots; on a drawn stretch they continue at a set spacing (S-8).

## The model in one paragraph

A pathway is a **route** plus its **timing**. The route is an ordered list of vertices from where
the move starts to where it ends; each vertex is a corner or smooth. The timing ties some route
points to counts (pins); between pins the marcher moves at even speed along the route's length.
Every case in the job list below is a setting of these two parts. A marcher who is not on a route
it should be on gets onto it with an **entry** (one rule, used for rejoins and joiners). Speed is
not constant across marchers: everyone moves at whatever speed their own path needs, and the
real constraint is no collisions (owner, 2026-11-02).
