# Collaboration: migrations for in-progress work

Collaboration work doesn't change other PRs (project owner, 2026-10-17). This note records what each
in-progress feature does today that real-time sync would need changed, so the change can be made
**after** that feature lands on `main`. Audit of the fork branches as of 2026-10-17. Keep it current
as branches land, and delete entries once they are migrated.

The rules each entry is checked against are in [GUARDRAILS.md](GUARDRAILS.md).
